# 🎆 Happy New Year 2026 Web Story 🎇

A festive New Year 2026 web story with a countdown timer, animated stars, interactive fireworks, and the ability to save a screenshot of the celebration. Perfect for sharing as a mini web story or embedding in your website.

---

## 🌟 Features

- **Countdown Timer**: Counts down to January 1, 2026.
- **Animated Stars**: Background stars twinkle and fall.
- **Fireworks Animation**: Automatic and click-triggered fireworks with optional sound.
- **Save Story**: Capture the screen and download it as a PNG image.
- **Responsive Design**: Works on both desktop and mobile screens.
